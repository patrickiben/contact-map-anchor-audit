# Anchor Audit Toolkit v0.2.0

This release accompanies the public draft **Auditing preprocessing-sensitive allele rankings in predicted chromatin contact maps**, in preparation for BMC Bioinformatics. It is not a journal submission or acceptance.

The paired IMR-90 test identified 49/84 centered leaders from native-only strengthened bounds versus 7/84 with simple bounds: 42 additional decisions across six genes, no observed contradictions, and 35 unresolved sites. Universal numerical saturation failed in three of 252 comparisons. Both methods abstained at those sites. This is a second output track within AlphaGenome at the same replication sites, not an independent model or experimental validation. RMS baselines remain stronger on selected-allele credit.

Included here:

- Current manuscript, six supplements and editable sources in the repository's `research/` directory.
- Complete scientific inputs, results and computational code in the three-part study archive below, including the earlier 750-file reproduction capsule.
- A compact scalar-verification dataset and independent verifier in `research/reproduce/`.
- Updated browser study summaries, source-bound study guide and full educational companion; human learner validation remains unperformed.
- An updated offline lab and source/version manifests.

Download all three `full-study-v0.2.0.zip.part-*` files plus `reassemble.py`, `REASSEMBLY_MANIFEST.json` and `SHA256SUMS.txt`. Read `README_REASSEMBLY.md`, then run `python3 reassemble.py`. The reassembler verifies part and whole-archive hashes and refuses to overwrite an existing output. Full stored-map replay requires the scientific environment recorded in the archive; scalar verification uses standard-library Python.
