02 / Use the instrument

Bring your own diagrams

Runs in your browser

Audit finite birth–death pairs and a declared shift for each alternate.

This tool starts from persistence diagrams. It does not infer diagrams from a contact map, select a biological anchor, or train a model.

  1. 1
    Supply the reference and alternate diagrams.
  2. 2
    Declare δ for each alternate. For mean centering, use the alternate-minus-reference map mean on the same edge support.
  3. 3
    Inspect the path and export distances, bounds and unresolved comparisons.

Browser limit: 20 points per diagram, 8 alternates, 2 MB per file. Empty diagrams and repeated points are supported. All coordinates must be finite with birth ≤ death. Use the Python toolkit for a larger audit.

Files are parsed locally. Their contents are never uploaded. The numerical allowance is practical floating-point tolerance, not a certified error bound.

Python toolkit & input format ↗

Pairs are [birth, death]. The optional selected field names an alternate; it does not influence distances.
