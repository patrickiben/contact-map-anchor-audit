# Targeted downstream propagation: implementation scope

Prepared before downstream execution. This note does not assert a successful result.

The comparison driver `scripts/compare_downstream.py` is independently written and does not import the original production analysis or witness modules. It consumes the frozen 72-diagram target: nine sites, two tracks and four alleles per site. No sites, alleles, endpoints or thresholds are selected using Julia outcomes.

Before any downstream matching for a site-track group, it checks the Julia receipts, raw-input and output hashes, original-result hash, finite positive and sorted intervals, exact complete interval-multiset equality, offsets, effective-input hashes, interval counts and independently recomputed map means. The expected input count `n` is the 512-bin matrix dimension, not the number of persistence intervals. Means from the existing analysis define the same centered comparison target; the means independently calculated from raw maps and the Julia receipt mean must each agree within absolute tolerance 1e-12.

The 108 native/centered bottleneck calculations use GUDHI/Hera with `delta=0`, the same solver as the prior analysis. Thus the independent component is the Julia persistence output and separately written downstream driver, not a second implementation of bottleneck matching. Centered diagrams are reconstructed by adding each map's saved mean to both interval coordinates, exactly as in the original target. No input is deduplicated.

The shifted Hausdorff check explicitly evaluates every reference/shifted-alternate off-diagonal point pair using blockwise SciPy `cdist(..., metric='chebyshev')`. It also retains each point's diagonal alternative, half its lifetime, before taking directed and symmetric maxima. This differs from the original `cKDTree` nearest-neighbor implementation. The frozen target entails 8,483,894,259 point-pair comparisons. With a block size of 256 and largest diagram size of 20,551, each distance block is at most about 42 MB; the complete pairwise matrix is never allocated. This is a lower bound that omits bijective matching constraints and must not be described as an independent bottleneck solver.

The script reconstructs simple and Hausdorff-strengthened score intervals, possible/necessary top-set members and guaranteed unique leaders using allowance 1e-12. It compares top sets and fractional credits at tolerances 0, 1e-6 and 1e-5. IMR90 has recorded native-only predictions at all three tolerances; the GM12878 standalone interval/ranking artifact records only 1e-6. The script compares all available recorded predictions and separately validates the newly reconstructed GM12878 predictions at the other two tolerances against their endpoints. The recorded-reference distinction is retained in the run metadata.

Finally, native/centered distances, shifted Hausdorff witnesses and numeric score bounds are compared within absolute tolerance 1e-12; top sets, credits, branch predictions and saturation flags must agree exactly. Primary nonsaturation uses 1e-10 with a 1e-12 sensitivity check. The aggregate check requires all and only the three previously declared IMR90 exceptions: site 48/ALT2, site 51/ALT1 and site 59/ALT0. Any discrepancy is retained in the per-site result and causes nonzero exit status. These tolerances are practical numerical comparisons, not certified real-arithmetic enclosures.

Execution requires an explicit `--primary-success-confirmed` flag and must occur only after the separate primary and known-answer checks have passed. The script is portable through `--study-root`, while reference-result paths are supplied by a regenerated manifest. The run metadata records source/protocol/manifest/reference hashes, environment versions, command, start/completion times and elapsed time.
