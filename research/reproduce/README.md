# Research verification and computational source

This is the final-proof revision of the compact scalar-verification bundle first published with [release v0.2.0](https://github.com/patrickiben/contact-map-anchor-audit/releases/tag/v0.2.0). The full raw-map/diagram archive is separately downloadable from that release. This revision preserves the scientific inputs and original analysis sources; [FINAL_PROOF_AMENDMENT.json](FINAL_PROOF_AMENDMENT.json) records the verifier and packaging changes. It is not a new genomic experiment or full persistence replay.

**AlphaGenome outputs and substantial derivatives are subject to [legally binding provider terms](OUTPUT_TERMS_NOTICE.md).** The original computational code is covered by [LICENSE_CODE_MIT.txt](LICENSE_CODE_MIT.txt). The data are not blanket MIT or unrestricted CC BY material. [MODIFICATIONS.md](MODIFICATIONS.md) records the author transformations and portability adaptations.

Run `python3 verify_derived_results.py --output verification.json` from this directory. Python 3.10 or later suffices; no third-party packages or API key are required. The output reconstructs 495 aggregate comparisons over 84 sites/252 pairs, including 7 versus 49 centered leaders, 42 added decisions and 249/252 saturation. This independently recalculates bounds, ranking sets and credits from saved scalar inputs; it does not regenerate PH, witness distances, matrix baselines or model predictions. The 495 comparisons cover 11 aggregate fields in each of 15 overall/gene/leave-one-gene-out scopes at three tolerances; the baseline-credit dictionary is compared as one aggregate field.

The verifier refuses Python optimization (`-O`, `-OO` or `PYTHONOPTIMIZE`) because optimization disables its assertions. It checks three finite values per allele vector, links the exploratory path endpoints and signed shifts to the corresponding endpoint records, and checks sampled path endpoints within the declared numerical allowance. Run `python3 test_verifier_controls.py --output scalar_controls.json` to repeat the positive comparison and 17 deliberate failure controls. [FINAL_PROOF_VALIDATION.json](FINAL_PROOF_VALIDATION.json) records the final-proof run; its positive result is byte-identical to the retained [DERIVED_VERIFICATION.json](DERIVED_VERIFICATION.json).

`analysis_source/` contains the scientific engine, acquisition adapter and tests. Full replay uses the maps and instructions in the complete release archive. Frozen protocols and timing records remain historical evidence; a rerun must make a fresh lock instead of pretending to recreate the original timing.

[PREPARATION_README.md](PREPARATION_README.md), [BUNDLE_VALIDATION.json](BUNDLE_VALIDATION.json), the `publication_status` field in `data/endpoint_scalars.json`, and `build_bundle.py` preserve the original preparation stage. Their private/unresolved-access and not-yet-uploaded wording is historical, superseded by the actual v0.2.0 release and current output-terms notice. The builder is the historical exporter, not a builder for this amended release. Retaining these bytes preserves the earlier source and result hashes; they do not describe the current access status.
